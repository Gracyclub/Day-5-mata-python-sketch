# 🌸 Navratri Day 5: Maa Skandamata Live Sketch Art 🌸

A real-time Python animation that sketches and renders the divine form of **Maa Skandamata** using computer vision techniques with OpenCV and NumPy.

---

## 🌟 Highlights
- **Live GUI Rendering:** Displays contour tracing and pen-stroke simulation directly inside an active OpenCV window.
- **Dynamic Pen Effect:** Smooth line-by-line drawing motion on a clean canvas.
- **Lightweight & Fast:** Runs purely on Python without complex rendering engines.

---

## 🚀 Quick Setup & Execution

### 1. Clone the Repository
    git clone [https://github.com/Gracyclub/day-5-mata-python-sketch.git](https://github.com/Gracyclub/day-5-mata-python-sketch.git)

### 2. Navigate to Project Directory
    cd day-5-mata-python-sketch

### 3. Install Dependencies
    pip install opencv-python numpy

### 4. Run the Code
    python day5.py
